## 五、真实代码缺陷（代码内部不一致，非文档问题）

1. 🔴 **恢复流程字段名 Bug**：`src-tauri/src/sync/restore.rs` 的补图步骤执行 `SELECT file_path, hash FROM asset`，而 `asset` 表实际列是 `rel_path`。结果：数据库还原成功后，补图查询必然报 `no such column: file_path`，补图被跳过并向上返回错误。
2. 🟡 **`ChatBox` 消息列表 `For key` 用 `role:content`**，两条相同内容的消息会导致 Leptos key 冲突（潜在渲染问题）。
3. 🟡 **`leptos_router` 是死依赖**：`frontend/Cargo.toml` 声明了 leptos_router，但全前端无任何路由使用。
4. 🟡 **`chat_session` / `chat_message` 僵尸表**：迁移建表但无任何读写代码。
