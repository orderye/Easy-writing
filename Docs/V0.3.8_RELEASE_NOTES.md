## 本版本包含

### 数据安全与可靠性（P0）

- 备份清单在恢复路径上真正生效：schema 版本、实体表计数、压缩包大小与 SHA-256、资产清单逐项校验，任一不符即拒绝覆盖。
- 清单损坏不再被当作「历史备份」降级处理；恢复失败有明确回滚或受控失败策略，回滚失败时快照保留。
- 本地配置 SQL 错误不再被吞掉；空库确认发生在覆盖之前，取消确认不修改任何数据。
- 完整证据见 [V0.3.8_RELEASE_ACCEPTANCE.md](https://github.com/orderye/Easy-writing/blob/main/Docs/V0.3.8_RELEASE_ACCEPTANCE.md)、[V0.3.8_P0_REPORT.md](https://github.com/orderye/Easy-writing/blob/main/Docs/V0.3.8_P0_REPORT.md)。

### 任务书 T02–T18

- **导出**：TXT / DOCX / EPUB，支持分卷结构、图片与章节标题样式（T02）。
- **备份与多设备**：备份保留策略与体积控制（T03）、跨设备覆盖保护（T04）、换设备密钥缺失统一处理（T05）。
- **写作与 AI**：上下文装配透明度与预算（T06）、提炼成本与去重（T07）、冲突检测结构化与本章忽略（T08）。
- **编辑体验**：全书搜索与批量替换（T09）、伏笔看板与回收章节（T10）、每日字数/专注模式/章节 POV（T11）。
- **发布与文档**：Asset 协议与 CSP 审计（T12）、更新校验和（T13）、三平台构建矩阵与条件式签名（T14）、WebDAV 明文警告（T15）、平台口径统一（T16）、体积口径与文档命名（T17）、CHANGELOG 与截图位（T18）。
- 数据库迁移累计至 **V009**，覆盖 v1→v9 连续升级与大数据迁移测试。
